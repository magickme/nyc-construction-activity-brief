Support and refund boundary for the current issue.

The product is a digital ZIP delivered by the browser after Stripe confirms payment. This page explains what to check if the download does not appear.

Delivery path

Stripe redirects completed buyers to /success.html?session_id={CHECKOUT_SESSION_ID}.

Download gate

/api/download verifies a paid completed Stripe Checkout Session before serving the ZIP.

Current ZIP

142 source-linked rows for the 2026-06-09 to 2026-06-15 source window.

If download fails

  1. Return to the Stripe confirmation page and use the success-page link with session_id in the URL.
  2. Use the same browser session if the first download attempt was interrupted.
  3. Keep the Stripe receipt email, success-page URL, approximate purchase time, and any visible error message.
  4. Do not send card numbers, bank details, passwords, or private account credentials.

Common download responses

Response Meaning
missing_or_invalid_session_id The success page URL is missing the Stripe session ID or the value is malformed.
payment_required Stripe did not confirm a paid completed Checkout Session for an accepted Payment Link.
session_verification_failed The server could not verify the Stripe session at that moment.
download_not_configured The paid ZIP is not configured on the server and should be treated as a delivery issue.

Refund boundary

This is a one-time digital ZIP purchase. Refund review should be based on duplicate charge, failed paid-session delivery, or a product file problem. No guaranteed leads. The ZIP does not include private contact data, owner names, applicant names, phone numbers, email addresses, full street addresses, or agency-endorsed information.
