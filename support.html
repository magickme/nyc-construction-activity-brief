If download fails

  1. Return to the Stripe confirmation page and use the success-page link with session_id in the URL.
  2. Use the same browser session if the first download attempt was interrupted.
  3. Keep the Stripe receipt email, success-page URL, approximate purchase time, and any visible error message.
  4. Do not send card numbers, bank details, passwords, or private account credentials.

Common download responses

Response Meaning
missing_or_invalid_session_id The success page URL is missing the Stripe session ID or the value is malformed.
payment_required Stripe did not confirm a paid completed Checkout Session for an accepted Payment Link.
session_verification_failed The server could not verify the Stripe session at that moment.
download_not_configured The paid ZIP is not configured on the server and should be treated as a delivery issue.
